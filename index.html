        Capture patches from the synth
        
Steps the synth through its programs with Bank Select and Program Change, reads each one, and adds it to the library. The synth's program changes while it runs, and its Program Change receive setting must be on. Each set has 5 groups, and a group is 5 banks of 8 programs (40 patches).
